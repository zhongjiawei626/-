# 检查看板

移动端优先的本机健康报告原型，界面参考 Apple Health 的卡片和趋势展示。数据源是用户选择的医院报告图片与 PDF；不预置 Excel 检查数据。

## 已提供的功能

- 一次选择多份 JPG、PNG、WebP、PDF，或选择“医院资料”文件夹批量导入。
- 浏览器本机 OCR 图片与 PDF 页面，显示候选指标供人工核对，并可校对日期、报告名与医院。
- 保留每份原始报告文件；指标结果可点击打开来源，报告页面可查看原件和 OCR 文本。
- 为明确的血糖、血清肌酐、胆固醇、甘油三酯、血红蛋白和 24 小时尿蛋白单位提供换算，并保留原始值与单位；其他单位变体会分开统计。
- 报告、OCR 与指标数据保存在当前浏览器的 IndexedDB/localStorage。

## 打开

通过本机 HTTP 服务或 Vercel 页面打开。OCR 组件、语言模型与 PDF 阅读组件首次使用时从 CDN 下载；文件内容和识别工作保留在浏览器本机。

## 限制

OCR 结果需要逐项核对。仅在指标和单位都明确时才换算；浏览器存储只在当前浏览器/设备中可见，清除浏览器数据会删除本机报告。此项目是 Web 原型，尚未封装为微信小程序。
