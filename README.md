# 本地健康报告档案

图片、PDF 原件保存在当前浏览器 IndexedDB，指标保存在 localStorage。上传时不调用云端 OCR 或语言模型，不使用 Gateway 密钥。

## 运行

`npm ci` 后执行 `npm run build`，将 `dist` 作为静态网站发布。首次识别下载 PaddleOCR PP-OCRv6 中文模型；模型可缓存，报告不随模型请求上传。PDF 使用 PDF.js 本地提取文字或渲染页面。运行库同站托管。

## 记录规则

用文字位置重组表格行，按已知检验项目读取数字、单位、参考范围。结果列在参考列之前、字段完整、OCR 分数达阈值的记录可自动进入趋势。带小于号/大于号的结果不会伪装为精确数值。未能可靠识别的项目保留为候选。单位换算保留原始单位和原值；不支持的单位独立统计。

`src/report-parser.mjs` 是不依赖浏览器的共享解析模块。`src/local-ocr.mjs` 是网页端识别适配器。当前产物是网页应用；微信原生小程序需要单独适配推理运行库、文件接口和存储，并在真机验证，不能直接上传网页作为原生小程序。

## 限制

自动入库规则降低误读风险，但 OCR 分数并不代表医学数据正确率。第一次模型加载较大，移动设备的耗时和内存需实测；不承诺识别所有医院格式。不要清除浏览器数据，除非已备份档案。

## 微信真机调试

原生调试工程位于 `wechat/`，AppID 已配置；使用微信开发者工具导入该目录。照片 OCR 为微信端侧能力适配，尚待真机确认；PDF 自动识别尚未迁移。详见 `wechat/README.md`。
