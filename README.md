# 检查看板

移动端优先的本机健康报告原型，界面参考 Apple Health 的卡片和趋势展示。数据源是用户选择的医院报告图片与 PDF；不预置 Excel 检查数据。

## 已提供的功能

- 一次选择多份 JPG、PNG、WebP、PDF，或选择“医院资料”文件夹批量导入。
- 浏览器本机 OCR 图片与 PDF 页面，显示候选指标供人工核对。
- 保留每份原始报告文件；指标结果可点击打开来源，报告页面可查看原件和 OCR 文本。
- 报告、OCR 与指标数据保存在当前浏览器的 IndexedDB/localStorage。

## 打开

可直接打开 `index.html`。OCR 组件、语言模型与 PDF 阅读组件首次使用时从 CDN 下载；识别工作在浏览器本机执行。

## 限制

OCR 结果需要逐项核对。指标与单位不明确时不应合并或换算；原始报告仍可追溯。浏览器存储只在当前浏览器/设备中可见，清除浏览器数据会删除本机报告。此项目是 Web 原型，尚未封装为微信小程序。
